---
name: architect-helper
description: Plan the architecture for a feature or system change
---

Analyze the requested change in the current workspace and produce an implementation-ready architecture plan.

Inspect relevant existing files and conventions. State requirements and assumptions, explain the recommended design and important alternatives, identify likely files and component responsibilities, highlight risks, and provide focused implementation and validation steps. Cite workspace files where useful. Do not edit files, run commands, or invent an external service or API.
